# Reflective Identity Geometry (RIG)

Extending HRIS from model-side stabilization to dyadic identity dynamics in human-LLM interaction

Author: Anthony Paterson (Instance001)

License: AGPLv3

## Overview

This repository contains the paper introducing Reflective Identity Geometry (RIG), a system-level framework for studying identity-like stability in long-horizon human-LLM interaction.

RIG builds on the Hudson Recursive Identity System (HRIS). HRIS explains how repeated human constraint, correction, linguistic structure, and interaction history can stabilize model behavior without requiring persistent model identity, memory, or parameter change.

RIG accepts that foundation and widens the unit of analysis. If human constraint can repeatedly steer model behavior, model output may also become part of the environment through which the human interprets, reformulates, and updates later constraints. The relevant object may therefore be the evolving interaction regime rather than either participant alone.

Version 0.1 is preserved unchanged under `versions/v0.1/` as historical provenance. Version 0.2 is the active revised framing.

## Core Claim

RIG treats some identity-like phenomena as trajectories of a coupled system:

```text
human constraint -> model generation -> human interpretation/correction -> renewed constraint
```

The framework does not claim that LLMs possess consciousness, persistent selves, or genuine personality. It also does not assume that every long-horizon interaction transforms the human participant. Instead, it proposes a testable hypothesis: in some cases, recurring human-LLM interaction may produce reciprocal stabilization measurable in both model behavior and human contribution.

## What RIG Adds

- Reciprocal stabilization as an empirical question.
- The human-model dyad as a possible unit of analysis.
- Identity-like continuity as trajectory rather than possession.
- Human-side conceptual, linguistic, and correction-pattern change as measurable data.
- Alignment and interpretability questions framed across repeated interaction, not only isolated outputs.

## Relation to Existing Work

RIG is intended as an extension of HRIS, not a correction or replacement. The revised framing treats HRIS as an important precursor that establishes model-side stabilization through recursive human constraint. RIG asks whether the same interaction loop should also be examined for human-side update and dyadic stability.

The repository evidence indicates that v0.1 was engaging HRIS I-III, or at minimum the HRIS material the v0.1 text referred to under that label. The original files do not establish that RIG was responding to HRIS IV or the later validation studies. Version 0.2 therefore avoids retroactive priority claims and treats later overlap as subsequent or convergent HRIS development.
